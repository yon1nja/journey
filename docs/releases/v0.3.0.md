# v0.3.0

Journey becomes a CLI-only tool that agents operate, per `docs/philosophy.md`.

- Released from: `release/v0.3.0`
- Previous release: `v0.2.0`

## Breaking changes

- The interactive TUI is removed (#9). Bare `journey` prints an overview and the active list.
- `~/.journey/config.toml` is no longer created or read. `journey migrate` removes it if it is still the default.

## Scope

- Refined Journey philosophy (#7).
- `journey close --outcome`, the `done` status, and `journey worktree new|remove` (#8).
- `journey guide`, with `~/.journey/JOURNEY-AGENTS.md` kept in sync with the binary (#10).
- `--json` output, `journey list --search` / `--all`, and a fuller `journey status` (#11).
- Side-quests, `journey relate|unrelate`, and `journey promote` (#12).
- `journey skills install|remove` for the bundled Claude Code skills (#13).
- `journey migrate [--dry-run]` to upgrade state from earlier versions (#15).

## Verification

- `cargo build`, `cargo test` and `cargo clippy` pass on the release branch.

## Upgrade notes

Run `journey migrate --dry-run`, then `journey migrate`, then `journey skills install`.
