# v0.3.0 Release Plan

**Status:** in progress
**Release branch:** `release/v0.3.0`
**Feature branch:** `feat/embedded-terminal`

## Summary

v0.3.0 delivers an embedded terminal workspace inside the Journey TUI: a new
`Screen::Workspace` mode with a sidebar listing Journeys and a terminal area
that hosts one or more shell tabs per Journey.

## Pivot: zellij plugin -> embedded terminal

The original plan for v0.3.0 was a zellij plugin (`feat/zellij-plugin-scaffold`)
that would let Journey drive terminal panes through zellij's plugin API. That
approach was scrapped in favor of embedding a terminal emulator directly in
the TUI, removing the zellij dependency and the requirement that users run
Journey inside a zellij session. The scaffold was removed and replaced with
the embedded-terminal dependencies (`alacritty_terminal`, PTY handling) in
commit `230c5c3`.

Embedding the terminal directly:
- works for any user regardless of their multiplexer/terminal setup
- keeps Journey a single self-contained binary
- gives full control over rendering, focus, and key routing instead of
  depending on zellij plugin API stability

## What's delivered

- `Screen::Workspace`: sidebar (journey list) + terminal area (tabs per
  journey), reachable from the List screen.
- Per-journey terminal tabs backed by a real PTY and VT100-compatible
  terminal emulator (`alacritty_terminal`), rendered into the TUI grid with
  full color/style support.
- Focus model: `Ctrl+H` toggles focus between sidebar and terminal;
  `Ctrl+Q` quits from either focus.
- Sidebar navigation: `j`/`k`/arrow keys to move, `Enter` to open a
  journey's terminal, `t` to open a new tab, `x` to close the active tab,
  `[`/`]` to switch tabs, `Esc` to return to the List screen, `a`/`d` for
  Actions/Details.
- Focus-dependent footer help text so the available shortcuts are always
  visible.
- Existing List/Search/Details/Actions screens are unchanged and remain
  fully functional.

## Out of scope / deferred

- Uppercase/digit/punctuation `Ctrl+<key>` combos are not correctly mapped
  to their terminal control byte in the key handler (only lowercase a-z is
  correct); tracked as a follow-up, not a blocker for this release.
- No persistence of terminal sessions across Journey restarts.

## Remaining before ship

- Manual interactive testing of the workspace (spawn shells, resize,
  multi-tab, focus switching) — not exercised by automated tests since
  they don't drive a real TTY.
- Version bump to `0.3.0` in `Cargo.toml` on the release branch.
- Final review + merge of `feat/embedded-terminal` into `release/v0.3.0`.
